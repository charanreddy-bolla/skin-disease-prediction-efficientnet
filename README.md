# Skin Disease Prediction using EfficientNet 🧠

## 📌 Overview
Deep learning-based skin disease classification system using EfficientNetB0.

## 🛠 Technologies
- Python
- TensorFlow
- CNN
- EfficientNetB0

## ▶️ How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Train model:
   python train_model.py

3. Predict:
   python predict.py

## 🎯 Goal
Automate skin disease detection using image classification.
